Code Examples

Array.diff KATA from CODEWARS (6 kyu): Implement a function that computes the difference between two lists. The function should remove all occurrences of elements from the first list (a) that are present in the second list (b). The order of elements in the first list should be preserved in the result.

C#

            using System.Linq;

public class Kata
{
    public static int[] ArrayDiff(int[] a, int[] b)
    {
        var query =
        from x in a
        where !b.Contains(x)
        select x;
        return query.ToArray();
    }
}

JavaScript

            function arrayDiff(a, b) {
    let res = Array.from(a);
    b.forEach( (nB) => {
        res = res.filter( (nR) => nR !== nB );
    });
    return res;
}
